# Privacy Policy

**Last updated: October 1, 2026**

This Privacy Policy explains how LDSApp handles personal data accessed through LinkedIn's Member Data Portability API.

## 1. Purpose

LDSApp is a personal, read-only integration used to access and analyze the LinkedIn data of the application owner for personal productivity and profile analysis purposes.

## 2. Data Accessed

Through LinkedIn's Member Data Portability API, LDSApp may access information made available by LinkedIn to the authorized member, such as:

- LinkedIn profile information
- Profile sections
- LinkedIn activity and related member data
- Recent changes to the member's LinkedIn data

LDSApp only accesses data for the LinkedIn member who explicitly authorizes the application.

## 3. Use of Data

The data accessed through LinkedIn is used solely for:

- Personal LinkedIn profile analysis
- Reviewing and improving profile content
- Personal productivity and related analysis

The data is not sold, rented, or used for advertising.

## 4. Data Storage

LDSApp is designed as a read-only integration. The application does not intentionally store LinkedIn member data on a separate database.

The LinkedIn access token is provided locally to the integration and is not intentionally shared publicly.

## 5. Data Sharing

LDSApp does not sell or share LinkedIn member data with third parties for advertising or marketing purposes.

Data may be processed by services explicitly used by the application owner to perform the intended personal analysis.

## 6. Data Security

Reasonable measures are taken to protect access credentials and prevent unauthorized access to LinkedIn data.

Access tokens and application credentials should be kept confidential and must not be publicly disclosed.

## 7. Data Retention and Deletion

The application owner may revoke LinkedIn authorization at any time through LinkedIn.

Because LDSApp is intended for personal use and does not intentionally maintain a separate database of LinkedIn member data, there is no separate user account or persistent LinkedIn data repository managed by LDSApp.

## 8. LinkedIn

LDSApp uses LinkedIn's APIs and is subject to LinkedIn's applicable terms and policies.

LDSApp is not affiliated with or endorsed by LinkedIn.

## 9. Contact

For questions regarding this Privacy Policy, please contact the application owner through the GitHub account associated with this repository.
